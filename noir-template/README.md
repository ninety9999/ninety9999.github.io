# NOIR — Portfolio Template

A modern, responsive portfolio template built with HTML, CSS, and JavaScript.

## Features
- Responsive design
- Project filtering
- Smooth animations
- Customizable colors
- No frameworks required

## Getting Started
1. Download and extract the ZIP file.
2. Open index.html in your browser.
3. Edit the content in index.html.
4. Edit the projects array in script.js.
5. Change --accent in style.css to customize the color.
